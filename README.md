# 📄 AI Resume Analyzer

An intelligent resume analysis tool powered by **OpenAI GPT** that gives you actionable feedback to improve your resume and land more interviews.

![Python](https://img.shields.io/badge/Python-3.9+-blue) ![Streamlit](https://img.shields.io/badge/Streamlit-1.32+-red) ![OpenAI](https://img.shields.io/badge/OpenAI-GPT--3.5-green)

## ✨ Features
- 📎 Upload PDF resumes and extract text automatically
- 🤖 AI-powered analysis using GPT-3.5
- 📊 Overall score, ATS score, and section-by-section breakdown
- ✅ Strengths & weaknesses identification
- 🔑 Missing keywords detection for your target role
- 💡 Personalized recommendations

## 🚀 Getting Started

```bash
# Clone the repo
git clone https://github.com/yourusername/ai-resume-analyzer
cd ai-resume-analyzer

# Install dependencies
pip install -r requirements.txt

# Run the app
streamlit run app.py
```

## 🛠️ Tech Stack
- **Streamlit** — Web UI
- **OpenAI GPT-3.5** — LLM analysis
- **PyPDF2** — PDF text extraction

## 📸 Demo
Enter your OpenAI API key in the sidebar, upload a PDF resume, set your target role, and click **Analyze Resume**.
